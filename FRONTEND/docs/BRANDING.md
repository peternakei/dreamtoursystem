# Dream Travel and Tours branding


| Color | Value | Usage |
| --- | --- | --- |
| Teal | #288479 | Default page background, header, sidebar, footer and login surround |
| Cream | #F7EFDF | Text on teal; cards, forms and menus |
| Orange | #FFA319 | Primary actions and selected navigation |
| Ink | #101010 | Text on cream surfaces and orange actions |
| Night | #080707 | Optional dark-theme background |

Vue tokens are in `src/style.css` and logo settings in `src/brand.ts`. Saved dark-mode preferences are respected. Switch to light mode to see the teal theme. Legacy Blade colors are in `public/assets/css/brand.css`. Quotation PDFs prefer the PNG; installations without GD PNG support fall back to the supplied black-background JPEG at `images/dream-logo-print.jpeg`.
